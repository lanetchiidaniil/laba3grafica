# Лабораторная работа 3 — фрактал Коллингвуда

Это графическое приложение на Pygame, визуализирующее фрактал Коллингвуда — алгебраическую вариацию семейства фракталов, близких к Burning Ship, но с формулой:

$$
z_{n+1} = (|Re(z_n)^2 - Im(z_n)^2| + c_x,\; 2|Re(z_n)Im(z_n)| + c_y)
$$

Приложение визуализирует фрактал в крупном окне, поддерживает интерактивное масштабирование, сброс масштаба, настройку количества итераций, отдельный фон и выбор палитры для фрактала и фона.

## Что реализовано

- вычисление фрактала Коллингвуда
- интерактивный zoom мышью
- сброс состояния по клавише `R`
- изменение числа итераций через `+` / `-`
- отдельная палитра для основного фрактала и для фона
- меню выбора палитры в интерфейсе
- режим headless для проверки и отладки
- увеличенное окно для комфортного просмотра

## Требования

- Python 3.13
- pip
- pygame
- numpy

## Запуск

1. Установите зависимости:
   ```powershell
   cd "C:\Users\User\Desktop\laba3grafica"
   py -3.13 -m pip install -r requirements.txt
   ```

2. Запустите приложение:
   ```powershell
   cd "C:\Users\User\Desktop\laba3grafica"
   py -3.13 main.py
   ```

3. Для задания числа итераций до запуска:
   ```powershell
   cd "C:\Users\User\Desktop\laba3grafica"
   py -3.13 main.py --iterations 220
   ```

4. Для headless-проверки:
   ```powershell
   cd "C:\Users\User\Desktop\laba3grafica"
   py -3.13 main.py --headless --iterations 20
   ```

## Управление

- `ЛКМ` — увеличить масштаб вокруг курсора
- `ПКМ` / `колесо` — уменьшить масштаб
- `R` — сброс к исходному виду
- `+` / `-` — изменить число итераций
- `Q` — следующая палитра для фрактала
- `E` — следующая палитра для фона
- `1` / `2` — быстрая установка числа итераций
- `Esc` — выход

## Примечание

Для этого проекта нужен именно Python 3.13. На Python 3.14 команда `pygame` может устанавливаться некорректно в текущем окружении, поэтому запуск рекомендуется делать через `py -3.13`.
