# Лабораторная работа 3 — Алгебраические фракталы

Приложение визуализирует фрактал Коллингвуда (перпендикулярный Горящий Корабль) в фиксированном окне с цветной градацией, масштабированием мышью, сбросом масштаба и настройкой количества итераций.

## Запуск

1. Установите зависимости:
   ```bash
   py -m pip install -r requirements.txt
   ```
2. Запустите приложение:
   ```bash
   py main.py
   ```
3. Для задания числа итераций до запуска:
   ```bash
   py main.py --iterations 220
   ```

## Управление

- Левая кнопка мыши — увеличить область вокруг курсора
- Колесо мыши — приблизить/отдалить
- R — сброс масштаба
- + / - — увеличить или уменьшить число итераций
- Esc / Q — выход
